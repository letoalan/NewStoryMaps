# Composant — Dashboard (`src/components/dashboard/Dashboard.tsx`)

Vue principale du tableau de bord affichant la liste des storymaps enregistrées localement dans le navigateur.

- **Fichier source** : [`src/components/dashboard/Dashboard.tsx`](file:///c:/Users/alano/OneDrive/Documents/GitHub/NewStoryMaps/src/components/dashboard/Dashboard.tsx)
- **Lignes** : 136

## Fonctionnalités
- Affichage de la grille de cartes (`StoryCard`) représentant chaque récit.
- Filtrage en temps réel par mot-clé (titre ou sous-titre) via la barre de recherche.
- Bouton d'importation de fichiers JSON StoryMap externes avec validation immédiate.
- Bouton de création rapide d'une nouvelle storymap.
- Gestion de l'état vide informatif avec illustration lorsque aucun récit n'est présent.
- Actions directes pour ouvrir l'éditeur, lancer le lecteur plein écran ou supprimer un récit.
