# Composant — TopBar (`src/components/editor/TopBar.tsx`)

Barre supérieure de l'éditeur fournissant la navigation de retour, la modification du titre et les actions de partage.

- **Fichier source** : [`src/components/editor/TopBar.tsx`](file:///c:/Users/alano/OneDrive/Documents/GitHub/NewStoryMaps/src/components/editor/TopBar.tsx)
- **Lignes** : 66

## Éléments
1. **Bouton Retour** : Retourne au tableau de bord.
2. **Champ Titre** : Permet la modification immédiate du titre principal du récit.
3. **Statut de Sauvegarde** : Affiche un indicateur dynamique avec point clignotant pendant l'enregistrement ou une coche verte lorsque le récit est sauvegardé dans IndexedDB.
4. **Bouton Export JSON** : Télécharge le fichier `.storymap.json`.
5. **Bouton Aperçu** : Ouvre la prévisualisation dans l'éditeur.
6. **Bouton Lire** : Bascule vers le mode de lecture immersif plein écran.
