# Composant : `RichTextToolbar.tsx`

Source : [`src/components/editor/RichTextToolbar.tsx`](file:///src/components/editor/RichTextToolbar.tsx)

## Rôle
Barre d'outils compacte insérant des balises de mise en forme (Markdown et enrichissements textuels) dans la zone de description d'une étape.

## Fonctionnalités
- Gras : `**texte**`
- Italique : `*texte*`
- Liens hypertextes : `[titre](url)`
- Citations : `> texte`
- Listes à puces : `- item`
