Racontez vos histoires sur une carte

StoryMap est un éditeur visuel de récits cartographiques. Vos lecteurs parcourent la page, la carte les emmène d’étape en étape. Un cours d’histoire, une étude de géographie, une sortie scolaire ou un itinéraire territorial : tout ce qui se déroule quelque part peut se raconter ainsi.

Lancer l'application Version historique

Aucune inscription requise : vos données restent enregistrées localement.

Trois modes

Choisissez votre mode de restitution

Mode 1 · Disponible

StoryMap classique

Récit guidé étape par étape, transitions cartographiques 3D, tableur intégré et médias.

Sorties : Web interactif, HTML autonome, JSON v2, Site ZIP.

Mode 2 · En finalisation

Document enrichi

Grille de blocs rectangulaires, cartes interactives synchronisées et mode présentation.

Sorties : Document HTML interactif, export ZIP.

Mode 3 · En finalisation

Brochure statique A4

Mise en page éditoriale A4 portrait/paysage, cartes vectorielles fixes et repères numérotés.

Sorties : Brochure A4 imprimable, export PDF haute fidélité.

Créer

Trois gestes, pas une ligne de code

  1. 1Écrivez sur la carte

    Titres, textes, images, vidéos : vous écrivez dans le panneau, comme dans un traitement de texte.

  2. 2Cadrez chaque chapitre

    Déplacez, zoomez, inclinez la carte : la vue est enregistrée automatiquement avec 8 fonds cartographiques.

  3. 3Ou partez de vos données

    Un tableur intégré, une ligne par chapitre, ou un fichier CSV/GeoJSON : chaque lieu devient un chapitre.

Partager

Une page web autonome, à publier ou à envoyer

L’export produit un seul fichier autonome incluant vos récits et le lecteur. Déposez-le sur tout hébergement statique ou partagez-le directement.

  • Page web autonome (.html) ou archive complète (.zip)
  • Fichier .json pour sauvegarder et réimporter vos projets
  • Barre de progression, sommaire et navigation clavier accessible
